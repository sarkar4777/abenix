# FieldEdge — Scaffolding Images

Source images for the FieldEdge wind-turbine maintenance showcase.
All five photos are reused under **CC BY-SA 2.0** with attribution to
the original photographer. They depict the same Scout Moor Wind Farm
(Rossendale, UK) construction and operation, which is convenient — the
visual scenery stays consistent across the demo.

## Mapping to the showcase storyboard

- **Hero / "Scan QR" card** -> `engineers_on_nacelle.jpg`
- **"Why it matters" climbing-safety section** -> `engineers_on_nacelle.jpg` or
  `working_on_hub.jpg`
- **Blade leading-edge erosion narrative** -> currently illustrated with
  `working_on_hub.jpg` (showing tip-of-tower work). Substitute a real
  erosion close-up if a public-domain one is added later.
- **Blade repair scaffolding / crane lift** -> `crane_lifting_gearbox.jpg`
  (same operation; conveys the scale of any major lift).
- **Nacelle / gearbox interior story** -> `nacelle_interior.jpg`,
  `gearbox_install.jpg`.

## QR turbine-plate (synthesised)

The "Scan QR" interaction in the UI is a button that pre-fills the
turbine selector — there is no real photo of a maintenance plate
shipped here. If a public-domain plate photo is added later, drop it
in as `qr_plate.jpg` and update the table above.
